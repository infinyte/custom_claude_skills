# Documentation

This folder is the repo-wide navigation layer for `AI-Agent-Skills`.

Use it when you want to understand what is in the repository without first picking a target
platform.

## Start Here

- `skill-index.md` lists every skill currently present in both package families and notes any
  packaging differences.
- `repository-layout.md` explains how the repository is organized today, including the current
  bundle-vs-folder differences between skill packages.

## Platform READMEs

- `../Claude Skills/README.md` documents the Claude-targeted packages.
- `../GitHub Copilot Pro Skills/README.md` documents the Copilot-targeted packages.

## Scope

These docs describe the repository as checked in here.

Per-skill usage and workflow details still live with each skill package in its `SKILL.md`, README,
references, examples, and scripts.
