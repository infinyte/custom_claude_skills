# Documentation and Diagram Update Checklist

After each implemented slice, inspect whether any of these require updates:

- README files
- API documentation
- OpenAPI / Swagger files
- Architecture docs
- ADRs
- Mermaid diagrams
- Draw.io diagrams
- Sequence diagrams
- Data flow diagrams
- Deployment diagrams
- Configuration docs
- Developer setup docs
- Test documentation
- Inline usage examples
- Changelog or release notes
- Markdown files in `docs/`

If a diagram exists and the slice changes behavior, architecture, dependencies, data flow, user flow, API flow, integration boundaries, or deployment topology, update it.

If nothing needs updating, record that explicitly in `implemented.md`.
