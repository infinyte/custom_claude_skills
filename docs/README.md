# Documentation

This folder is the repo-wide navigation layer for `AI-Agent-Skills`.

Use it when you want to understand what is in the repository before opening any individual skill
folder.

## Start Here

- `skill-index.md` lists every skill currently present in this repository, plus per-skill
  structure and documentation status.
- `repository-layout.md` explains how the repository is organized today and highlights known
  standardization gaps.

## Main READMEs

- `../Claude Skills/README.md` documents the Claude-targeted packages.
- `../README.md` is the root entry point for repository-wide orientation.

## Scope

These docs describe the repository as checked in here.

Per-skill usage and workflow details still live with each skill package in its `SKILL.md`,
`references/`, examples, and scripts.

The execution roadmap for repository standardization is documented in
`standardization-plan.md`.
